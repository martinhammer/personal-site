Here are a few useful commands for finding version information of various system components.

- Linux distribution name and version

  ```bash
  lsb_release -idrc
  ```
- System information, including kernel version

  ```bash
  uname -a
  ```
- X.org version

  ```bash
  X -version
  ```
- Java version

  ```bash
  java -version
  ```
- Package version

  ```bash
  dpkg -s <insert package name>
  ```
