[nautilus-image-converter](http://packages.ubuntu.com/jaunty/nautilus-image-converter) is a helpful package which adds two entries to the Nautilus context menu for resizing and rotating images. It works for selections of multiple images, too, and has options for creating copies or editing the images in place.

To install from command line:

`sudo apt-get install nautilus-image-converter`
