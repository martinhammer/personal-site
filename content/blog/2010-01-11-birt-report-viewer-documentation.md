Eclipse BIRT comes with Report Viewer, a J2EE application used for generating and displaying reports. Whilst deploying and using the out-of-the-box application on Tomcat is [straightforward](http://www.eclipse.org/birt/phoenix/deploy/viewerSetup.php), there are fairly rich configuration and parametrization options which are non-obvious. The following two documents describe how the viewer works and how to control its behaviour.

- [BIRT Viewer User's Guide](http://www.birt-exchange.org/modules/wfdownloads/visit.php?cid=5&lid=492) (covers version 2.3, PDF)
- [Using the BIRT Report Viewer](http://www.eclipse.org/birt/phoenix/deploy/viewerUsage2.2.php) (covers version 2.2)
