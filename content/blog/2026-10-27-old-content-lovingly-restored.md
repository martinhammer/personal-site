The old content on this blog comes from my blog called "The Empty Quarter" which was hosted on [martinhammer.com](http://martinhammer.com) roughly between 2009 and 2020. The purpose of that blog was to record little how-to snippets and links mainly to do with Ubuntu and Linux in general, and [BIRT](https://en.wikipedia.org/wiki/BIRT_Project) which is a tool I was using at work at the time. There isn't much value in the content from a technical point of view; from the curiosity perspective it is perhaps an interesting look back in time.

The content was restored from an old WordPress backup. The posts were converted into Markdown with the help of Claude AI. This site is built using the [Zola static site generator](http://www.getzola.org/), using those Markdown files as input.
